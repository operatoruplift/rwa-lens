# RWA Lens capability matrix

Evidence date: **19 September 2026 UTC / 20 September 2026 local**. This matrix
reports the highest state established by the linked evidence, not a blanket
completion badge. In particular, a live RPC read served locally is
`live-read-verified`, not `hosted-verified`.

State vocabulary:

- `implemented-unverified`: code/configuration exists, but the relevant journey
  has not yet been exercised.
- `locally-tested`: deterministic tests or a local production browser journey
  passed; this does not claim a real external integration.
- `live-read-verified`: an actual external read has a recorded receipt, within
  the stated scope.
- `hosted-verified`: the current release was exercised through its deployed URL.
- `disabled-optional`: optional functionality is intentionally not exposed.
- `blocked-required`: a required capability or required release proof remains
  unavailable; the blocker and next action are explicit.

scope. [Setup](../README.md), [limitations](rwa-limitations.md),
[demo script](rwa-demo-script.md), and [deployment/rollback](rwa-deployment.md)
